## ドラマトゥルギー設計

### 発端 (Inciting Incident)
フォン・ローゼン男爵家の借金が限界に達する。取り立て人が屋敷に来る日の朝、シグヴァルト・フォン・ベルンハルト公爵から一通の手紙が届く。「令嬢の身柄と引き換えに、一切の負債を消却する」。エルサは翌日、一人で公爵邸の門をくぐる。

### 目標 (Goal)
エルサ: 家族の安全を確保し、この状況を生き抜くこと。
シグヴァルト: エルサを確実に手元に置くこと——逃げられないよう。

### 障害 (Obstacle)
- エルサの誇りと恐怖の葛藤
- シグヴァルトの「触れない」という謎の方針（エルサにとって不気味）
- 使用人たちの視線（新参者への観察と品定め）

### 葛藤 (Conflict)
*外的葛藤:* 見知らぬ屋敷に閉じ込められる現実・シグヴァルトの命令への服従
*内的葛藤:* 怯えながらも、シグヴァルトの存在に抗えない磁力を感じる自分への嫌悪

### クライマックス (Arc1クライマックス・第3話)
社交界の夜会で、エルサを「狙う」貴族男性が現れる。シグヴァルトが「救済」という名の支配を発動——彼女を人前で公爵の「保護下」に置くことを宣言する。エルサは救われたと同時に、より深く籠に嵌まったことを悟る。

### 結末 (Resolution)
エルサは「逃げない」のではなく「逃げられない」という事実と、もう一つの事実——「逃げたくない瞬間がある」という自分の感情の発芽——を同時に抱えてArc2へ進む。

## 話数別 5W1H プロット

### 第1話「契約の夜」

| 要素 | 内容 |
|------|------|
| **Who** | エルサ、シグヴァルト |
| **What** | エルサが公爵邸に到着し、契約書に署名する。最初の夜、シグヴァルトは指一本触れずに「逃げられないことを自覚しろ」とだけ告げる。 |
| **Where** | フォン・ローゼン男爵邸（冒頭）→ 馬車の中 → ベルンハルト公爵邸・応接間・エルサの寝室 |
| **When** | 物語の「現在」Day 0→1 |
| **Why** | 家族の借金返済のため。シグヴァルトにとっては10年間探し続けた女を手に入れるため。 |
| **How** | 冷徹な取引として始まるが、シグヴァルトの「触れない」行動がエルサを不気味に揺さぶる。 |
| **感情目標** | 恐怖・覚悟・そして最初の「不可解さ」——この男は何故、ただ私を見る？ |
| **テンション値** | 6 |
| **伏線（埋め）** | シグヴァルトがエルサの亜麻色の髪を一瞬だけ、静かに見つめる（10年前の記憶）。エルサの左手首に古い傷跡（Arc3の伏線）。 |
| **伏線（回収）** | なし |
| **次話への繋ぎ** | 寝室で一人になったエルサが窓の格子を触り「美しい籠だわ」と呟く。翌朝の食事に、自分の好みが完璧に反映されていることに気づく。 |

### 第2話「金の檻の住人」

| 要素 | 内容 |
|------|------|
| **Who** | エルサ、シグヴァルト、使用人頭（マーゴット） |
| **What** | 公爵邸での最初の1週間。エルサは「管理」の全容を少しずつ把握していく。食事・衣装・就寝時間——全てが把握・管理されている。 |
| **Where** | ベルンハルト公爵邸（寝室、食堂、温室への道） |
| **When** | Day 1〜7 |
| **Why** | シグヴァルトにとってこれは「当然」の管理。エルサを「守る」ことと「支配する」ことの区別が彼には存在しない。 |
| **How** | 細部の管理に気づくたびエルサは怒りを感じるが、表に出せない。しかし温室を見つけた瞬間、初めて心が解ける。 |
| **感情目標** | 困惑・怒り・そして予期せぬ「この場所の美しさ」に揺れる |
| **テンション値** | 5 |
| **伏線（埋め）** | 温室の南方の花。シグヴァルトが「お前が好きそうだと思った」と言う代わりに何も言わずその場を去る。 |
| **伏線（回収）** | なし |
| **次話への繋ぎ** | 王立夜会への招待状が届く。「私の隣に立て」という一言と共に。 |

### 第3話「社交界の檻」

| 要素 | 内容 |
|------|------|
| **Who** | エルサ、シグヴァルト、侯爵令息（悪役・一時登場）、社交界の貴族たち |
| **What** | 王立夜会に連れ出されたエルサが、侯爵令息に言い寄られ危機に陥る。シグヴァルトが宣言する——「この女は私の保護下にある。触れた者の末路は覚悟しろ」。 |
| **Where** | 王立歌劇場・夜会会場 |
| **When** | Day 10頃 |
| **Why** | シグヴァルトはエルサを「見せる」ことで、誰も近づけない結界を張ろうとしている。 |
| **How** | 危機の瞬間、シグヴァルトの存在が「安堵」として現れる。これがエルサの中の何かを変える。 |
| **感情目標** | 恐怖→救済→しかしその救済が新たな鎖であると悟る複雑さ |
| **テンション値** | 7 |
| **伏線（埋め）** | 夜会での王太子の視線（Arc2・政争の種）。シグヴァルトが初めてエルサの名前を呼ぶときの僅かな声の変化。 |
| **伏線（回収）** | なし |
| **次話への繋ぎ** | 帰路の馬車の中。暗闇の中でシグヴァルトの銀眼だけが光る。「怖かったか」——問いではなく、確認として。エルサは「……少しだけ」と答える。これが二人の初めての「会話」。 |
